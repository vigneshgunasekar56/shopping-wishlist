##Wishlist Locker

##What Wishlist Locker is for?

This app Wishlist Locker is to keep track of your wishlist of purchases
and whether you have achieved your target.

##Slice your idea into a first version
    App is to keep track of the wishlist and how much money require to fullfil
    the purchase of wishlist.

##Three features the first version will have
  1.  Inputs to get information from the user
  2.  Storage to sustain the stored information without losing even after
    reload
  3.  List to see and track the wishlist
  4. The total amount need to accomplish purchasing the wishlist
  
  
 Features to add on later
    1. Local Storage to API
    2. Connecting to real database
